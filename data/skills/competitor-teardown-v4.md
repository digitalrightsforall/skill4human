# 智慧逆向工程报告：Adversarial Competitor Teardown (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 竞品发布重大更新、进入新市场、或需要制定年度防御战略时。
- **启动信号**: 当你发现“对手最近动作频频”或者“我们的老客户正在流失”时。
- **[启发式准则]**: 竞品是你最好的老师，它用真金白银帮你测试了哪些路径是死路。

## 核心心法 / Philosophy
- **看透权衡 (Trade-offs)**: 所有的战略都是放弃。竞品选择了 A，就必然放弃了 B。你的机会就在 B 里。
- **成本结构推演**: 估算对手的团队规模、营销支出和获客成本。看清它是靠“钱”烧出来的，还是靠“产品”跑出来的。
- **[认知增益]**: 获得“动态竞争感”，不再被动挨打，而是学会借力打力。

## 落地模型 / System
- **拆解五步法**: 
  1. **价值主张**: 它到底在向用户许诺什么？（看官网第一屏）。
  2. **用户流转**: 模拟新用户，走完它所有的购买/使用路径。哪里最丝滑？哪里最卡顿？
  3. **盈利真相**: 它的哪个功能是用来获客的？哪个是用来赚钱的？
  4. **产品架构**: 它的系统逻辑是封闭的还是开放的？
  5. **致命弱点**: 如果你要击败它，你会在哪个点进行“非对称打击”？
- **[反面模式]**: 盲目抄袭。看到竞品加了功能就跟着加，完全不考虑自己的战略定位。

## 执行动线 / Workflow
1. **身份伪装**: 作为一个极度挑剔的客户去试用。 -> 2. **逻辑逆向**: 倒推它的功能优先级（看它把什么放在了导航栏最显眼的位置）。 -> 3. **影子复盘**: 假如你是对方的 PM，你会怎么做下一版本？ -> 4. **差异化定位**: 找出那个竞品“想做但因为历史包袱做不了”的切口。

## 实战技巧 / Tactic
- **招聘启事分析**: 通过竞品在招什么样的人，判断它未来的技术走向和战略重心。
- **[启发式准则]**: 最危险的竞争对手往往不是长得像你的，而是那个用完全不同的逻辑解决同一问题的。
- **[认知增益]**: 提升“战略敏锐度”，在红海中发现蓝海。
