# 智慧逆向工程报告：Zettelkasten Logic (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 进行长期课题研究、撰写书籍、或需要建立个人庞大知识体系时。
- **启动信号**: 当你发现自己存了成千上万条笔记，但在写作时却一条也用不上时。
- **[启发式准则]**: 笔记不是为了保存，而是为了在未来“不期而遇”。

## 核心心法 / Philosophy
- **原子化原则 (Atomicity)**: 一张卡片只讲一个观点。这让知识可以像乐高积木一样被任意组合。
- **链接优先于存储**: 知识的价值在于它与其他知识的“联结”。没有链接的笔记就是死数据。
- **[认知增益]**: 获得“思想复利”，建立一个能自我演化的“第二大脑”。

## 落地模型 / System
- **卡片盒三原色**: 
  1. **闪念笔记 (Fleeting Notes)**: 随时捕捉的灵感，24 小时内必须处理。
  2. **永久笔记 (Permanent Notes)**: 用自己的语言重构后的完整观点。
  3. **结构笔记 (Structure Notes)**: 索引和脉络，将相关的卡片串联起来。
- **[反面模式]**: 剪报狂。直接复制粘贴原文，不做任何处理。

## 执行动线 / Workflow
1. **捕捉**: 随时记下闪念。 -> 2. **重构**: 用自己的话复述，并思考“这和我已有的哪张卡片有关系？” -> 3. **双向链接**: 强制建立至少 2 个跨领域的链接。 -> 4. **漫游**: 定期通过链接进行思维漫游，寻找新的碰撞点。

## 实战技巧 / Tactic
- **使用 ID 编码**: 给卡片一个唯一的地址，方便在任何地方引用。
- **[启发式准则]**: 如果你不能用一句话概括出这张卡片与另一张卡片的关系，那这个链接就是无效的。
- **[认知增益]**: 提升“创造力”，让新想法从旧知识的缝隙中自动生长出来。
