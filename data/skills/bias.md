# 智慧逆向工程报告：Cognitive Bias Auditor (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 团队决策会、个人投资判断、或者在对某件事感到“绝对确定”时。
- **启动信号**: 当你感到某种强烈的情绪（如：极度兴奋或极度厌恶）正在主导你的判断时。
- **[启发式准则]**: 大脑的默认状态是为了节省能量，而不是为了寻找真相。

## 核心心法 / Philosophy
- **元认知监视**: 观察你在观察什么。意识到你的思维存在“盲点”。
- **证伪优先**: 不要寻找支持你观点的证据，要寻找能推翻你观点的证据。
- **[认知增益]**: 获得“决策净值”，降低在重大问题上犯低级错误的概率。

## 落地模型 / System
- **核心偏误审计清单**: 
  1. **确认偏误**: 我是否只听我喜欢的观点？
  2. **沉没成本**: 我是否因为“已经投入了这么多”而拒绝止损？
  3. **可得性偏差**: 我是否因为最近刚发生这件事，就觉得它发生的概率很大？
  4. **锚定效应**: 我是否被对方给出的第一个数字限制了思维？
- **[反面模式]**: 直觉至上。认为“我的直觉从来没错过”，这通常是由于幸存者偏差。

## 执行动线 / Workflow
1. **情感标注**: 识别当前决策背后的情绪底色。 -> 2. **清单对照**: 强制运行偏误审计清单。 -> 3. **对抗性演练**: 站在反方立场写出 3 个不执行该决策的理由。 -> 4. **统计复核**: 回归到底层的概率和数据，而非故事。

## 实战技巧 / Tactic
- **事前尸检**: 假设该决策在一年后惨败，倒推失败的原因。
- **[启发式准则]**: 如果一个决定让你感到非常“爽”，那你很有可能正处于某个偏误的包围中。
- **[认知增益]**: 提升“理性的深度”，成为那个在疯狂人群中保持冷静的人。
