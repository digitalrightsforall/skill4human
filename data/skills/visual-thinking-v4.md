# 智慧逆向工程报告：Visual Logic Systems (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 设计复杂架构、梳理多因果关系链、或需要向团队传达高度抽象的愿景时。
- **启动信号**: 当你发现自己用了 10 分钟还没讲清楚一个逻辑关系时，立即拿起笔。
- **[启发式准则]**: 图表是思想的载体，不是装饰品。

## 核心心法 / Philosophy
- **空间化记忆**: 大脑对位置的记忆远强于对文字的记忆。
- **降低认知负荷**: 将线性的文字转化为并行的视觉流。
- **[认知增益]**: 获得“全局掌控感”，在脑中建立起一座可以随时缩放、旋转的智慧宫殿。

## 落地模型 / System
- **视觉思考三支柱**: 
  1. **实体 (Entities)**: 核心要素（用方块或圆形表示）。
  2. **连接 (Connections)**: 因果、包含、或流程关系（用箭头表示）。
  3. **属性 (Attributes)**: 关键特征（用标签或颜色表示）。
- **[反面模式]**: 过度美化。把精力花在画得漂亮上，而非画得准确。

## 执行动线 / Workflow
1. **元素提取**: 找出一件事中所有的核心参与者。 -> 2. **关系建模**: 在白纸上连线，寻找环路、瓶颈和孤点。 -> 3. **维度折叠**: 将复杂的细节隐藏在抽象层级之下。 -> 4. **动态演示**: 通过在图上“行走”来测试逻辑是否通畅。

## 实战技巧 / Tactic
- **餐巾纸草图**: 最好的视觉思考通常发生在一张随手可得的纸上。
- **[启发式准则]**: 如果一张图超过了 3 种颜色或 3 种形状，它的传播效率就会开始急剧下降。
- **[认知增益]**: 提升“沟通穿透力”，让对方不仅听见，而且“看见”你的思想。
