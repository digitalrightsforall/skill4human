# 智慧逆向工程报告：High-Resolution Empathetic Feedback (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 绩效面谈、代码评审、或在家庭关系中需要指出对方的错误时。
- **启动信号**: 当你感到“我有意见，但我怕说了会伤关系”或“我说了，但对方跳起来反驳”时。
- **[启发式准则]**: 反馈不是为了评判过去，而是为了设计未来。

## 核心心法 / Philosophy
- **对事不对人 (Behavior over Personality)**: 你反馈的是“行为”带来的“后果”，而不是对方的“人品”。
- **观察而非评价**: “你最近迟到了三次”是观察；“你这人没责任心”是评价。评价必然诱发防御。
- **[认知增益]**: 获得“心理外科手术”的能力，精准切除问题而不伤及健康组织（关系）。

## 落地模型 / System
- **SBI 反馈模型**: 
  1. **Situation (情境)**: 具体的、发生的时间和地点。
  2. **Behavior (行为)**: 你观察到的具体动作（不是你的揣测）。
  3. **Impact (影响)**: 这个行为对团队、业务或对你的具体影响。
- **[反面模式]**: 三明治反馈。在两个表扬中间塞一个批评。这种做法极其虚伪，会导致对方以后对你的表扬产生怀疑。

## 执行动线 / Workflow
1. **申请许可**: “关于刚才的会议，我有几个观察想跟你交流一下，现在方便吗？” -> 2. **陈述事实 (SBI)**: 极简地叙述发生的经过。 -> 3. **共同探因**: 问“我是这么看的，你的视角是怎样的？” -> 4. **制定对策**: 让对方提出改进方案，并达成一致。

## 实战技巧 / Tactic
- **使用“我”语句**: “我觉得这让我很困扰”比“你这人真烦”好得多。
- **[启发式准则]**: 一个好的反馈应该让对方感到“虽然被扎了一下，但确实看清了路”。
- **[认知增益]**: 提升“关系韧性”，在保持高标准的同事维持深度的信任。
