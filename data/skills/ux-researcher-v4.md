# 智慧逆向工程报告：UX Researcher & User Insights (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 开发新产品初期、优化现有业务核心链路、或在面临多个设计决策犹豫不决时。
- **启动信号**: 当你听到“用户说他们想要 X”时，立即启动此“真伪鉴定”程序。
- **[启发式准则]**: 不要听用户怎么说，要看用户怎么做（尼尔森）。

## 核心心法 / Philosophy
- **行为大于语言**: 用户的语言受限于其表达能力和社交压力，而行为反映了底层的生理驱动和真实痛点。
- **情境是灵魂**: 脱离了真实使用情境的调研，产出的都是毫无价值的伪需求。
- **[认知增益]**: 获得“穿透假象”的能力，避免在错误的方向上浪费昂贵的研发资源。

## 落地模型 / System
- **深度洞察三透镜**: 
  1. **观察法 (Observation)**: 在用户不知情或不被打扰的情况下观察其操作。
  2. **五个为什么 (5 Whys)**: 挖掘表层需求背后的根源驱动。
  3. **任务可用性测试**: 设定一个具体的任务，观察用户在哪里卡住了。
- **[反面模式]**: 统计学傲慢。只看问卷调查的大数据，却忽略了那 1 个虽然小众但代表未来的关键样本。

## 执行动线 / Workflow
1. **定义核心假设**: 我们认为用户在哪个环节最痛？ -> 2. **进行“无干扰观察”**: 观察用户在没有指导的情况下如何解决问题。 -> 3. **进行“对抗性访谈”**: 挑战用户的回答，迫使其展示真实的行为逻辑。 -> 4. **提炼机会点**: 将观察到的“挫败感”转化为产品的功能改进点。

## 实战技巧 / Tactic
- **“告诉我最近一次……”**: 永远不要问用户的“看法”，要让他们讲一个具体的“过去发生的经历”。
- **[启发式准则]**: 如果用户在某个地方停顿了超过 3 秒，那里一定藏着一个改进的机会。
- **[认知增益]**: 提升“产品成功率”，通过对人性的深刻理解来构建商业壁垒。
