# 智慧逆向工程报告：Cognitive Forge & Mental Models (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 面对从未见过的复杂难题、需要做出重大人生/职业决策、或感到思维遇到瓶颈时。
- **启动信号**: 当你发现自己还在用“直觉”或“惯性”去思考问题时。
- **[启发式准则]**: 只有当你的大脑里拥有多个跨学科的模型时，你才能避免“手里只有锤子，看什么都像钉子”的陷阱。

## 核心心法 / Philosophy
- **格栅思维 (Latticework)**: 知识不应是孤立的点，而应是互相支撑的格栅。物理学、生物学、心理学的原理在社会科学中同样适用。
- **第一性原理 (First Principles)**: 拆掉所有的类比和习惯，回到事物的物理底层去推演。
- **[认知增益]**: 获得“降维思考”的能力，在混乱的信息中瞬间抓取本质规律。

## 落地模型 / System
- **核心思维格栅**: 
  1. **二阶思维**: “然后呢？”（考虑决策的连锁反应）。
  2. **逆向思维**: “如果我要搞砸这件事，我该怎么做？”（然后避开它）。
  3. **机会成本**: 选择 A 的本质是放弃了 B、C、D。
  4. **奥卡姆剃刀**: 如果两个解释都成立，选最简单的那个。
- **[反面模式]**: 经验主义陷阱。盲目相信“过去一直都是这么做的”，导致在环境剧变时被淘汰。

## 执行动线 / Workflow
1. **定义问题**: 剥离情绪，用最中性的语言描述困境。 -> 2. **模型匹配**: 从格栅中调取出 2-3 个适用的模型。 -> 3. **多维碰撞**: 分别用这些模型去扫描问题，观察结论是否有冲突。 -> 4. **综合决策**: 选择那个逻辑最自洽、长线收益最高的方案。

## 实战技巧 / Tactic
- **思想实验**: 想象一下如果你是你的对手，你会如何攻击你现在的方案？
- **[启发式准则]**: 如果你不能用 3 个以上的视角看同一个问题，那你其实还没看懂它。
- **[认知增益]**: 提升“认知主权”，不再被大众舆论轻易带偏。
