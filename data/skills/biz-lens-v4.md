# 智慧逆向工程报告：Business Multi-Lens System (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 评估新业务机会、进行季度业务审计、或在现有业务遭遇增长瓶颈时。
- **启动信号**: 当你感到“利润微薄”或“竞争过于激烈”时。
- **[启发式准则]**: 优秀的商人看到的不是产品，而是资产的周转率和利润的结构。

## 核心心法 / Philosophy
- **盈利是设计出来的**: 不要指望努力工作就能赚钱，要指望“结构化优势”。
- **单位经济模型 (Unit Economics)**: 如果你每卖出一件产品都在亏钱，那么规模化只会加速你的死亡。
- **[认知增益]**: 获得“商业 X 光眼”，看透任何繁杂业务背后的金钱流向和逻辑盲区。

## 落地模型 / System
- **五维盈利透镜**: 
  1. **LTV/CAC 比率**: 客户终身价值是否至少是获取成本的 3 倍？
  2. **边际成本**: 增加一个新用户，你的成本是趋于零还是线性增长？
  3. **护城河**: 品牌、网络效应、专利还是极高的转换成本？
  4. **现金流循环**: 钱是先收进来还是先付出去？
  5. **关键杠杆点**: 业务中哪一个 1% 的改变能带来 50% 的利润提升？
- **[反面模式]**: 虚荣指标。沉迷于用户数、点击率，而忽略了真实的现金流和利润率。

## 执行动线 / Workflow
1. **剥离表象**: 强制忽略所有的营销话术，只看资产负债表。 -> 2. **压力测试**: 假设原材料价格上涨 20%，这门生意还成立吗？ -> 3. **寻找非对称性**: 找出那个低投入、高产出的盈利切口。 -> 4. **模型重构**: 优化收费模式（如：从一次性收费转为订阅制）。

## 实战技巧 / Tactic
- **10 倍定价法**: 如果你敢把价格提高 10 倍，你需要提供什么样的服务？这能帮你找到核心价值。
- **[启发式准则]**: 如果你不能用一句话说清楚你赚的是谁的钱、为什么是你的，那说明你还没看懂这门生意。
- **[认知增益]**: 提升“财务自由”的概率，通过理性的商业设计而非盲目的勤奋获胜。
