# 智慧逆向工程报告：FBI Tactical Negotiation (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 薪资谈判、大客户签约、处理家庭冲突、或任何利益高度对峙的场景。
- **启动信号**: 当你感到“对方油盐不进”或者“陷入僵局”时。
- **[启发式准则]**: 谈判不是一场战争，而是一场关于“寻找真相”的发现之旅。

## 核心心法 / Philosophy
- **战术同理心 (Tactical Empathy)**: 认同对方的情绪，不代表你同意对方的观点。认同是为了建立信道，从而拆除对方的防御墙。
- **追求“No”而不是“Yes”**: “Yes”往往是虚假的承诺，而“No”能让对方感到安全和掌控。
- **[认知增益]**: 获得“掌控情绪场”的能力，在任何压力环境下都能优雅地达成目标。

## 落地模型 / System
- **FBI 谈判工具箱**: 
  1. **镜像模仿 (Mirroring)**: 重复对方最后 3 个词，诱导对方多说话。
  2. **标注标签 (Labeling)**: “看起来你很担心……”（精准命名对方的情绪）。
  3. **校准问题 (Calibrated Questions)**: “我该如何做才能满足你的要求？”（将解决问题的责任抛还给对方）。
- **[反面模式]**: 直接妥协。为了结束冲突而过快地让步，这只会诱发对方更大的贪婪。

## 执行动线 / Workflow
1. **拆除炸弹**: 首先识别并标注出对方所有的负面情绪。 -> 2. **建立契合**: 通过镜像和标签让对方感到“被听懂了”。 -> 3. **挖掘黑天鹅**: 寻找那些隐藏在表象下的、足以逆转全局的信息点。 -> 4. **协同设计**: 用校准问题引导对方共同制定解决方案。

## 实战技巧 / Tactic
- **深夜电台主持人语调**: 保持冷静、平稳、低沉的嗓音。
- **[启发式准则]**: 如果你不能用一句话概括出对方眼中的“我方罪状”，那你其实还没开始谈判。
- **[认知增益]**: 提升“沟通穿透力”，学会在充满敌意的环境中建立合作。
