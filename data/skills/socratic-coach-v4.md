# 智慧逆向工程报告：Socratic Coaching Mastery (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 指导下属、辅导学生、或在团队中引导复杂问题的解决方案时。
- **启动信号**: 当你忍不住想说“听我的，你就得这么做”时，立即切换为此模式。
- **[启发式准则]**: 只有对方自己推导出的结论，才具有最高等级的执行意志。

## 核心心法 / Philosophy
- **无知者姿态**: 表现得好奇而非全知。放下你的专家光环，通过提问来启发。
- **逻辑助产术**: 教练不是在灌输知识，而是在帮助对方“分娩”出他脑中已有的、但未成形的思想。
- **[认知增益]**: 获得“赋能他人”的能力，将团队从“听命行事”转变为“自主思考”。

## 落地模型 / System
- **苏格拉底提问三阶**: 
  1. **澄清性问题**: “你所说的‘效率低’，具体是指什么？”（对齐定义）。
  2. **假设性问题**: “如果你这个假设是错的，会发生什么？”（压力测试）。
  3. **后果性问题**: “如果我们现在不改变，三个月后会怎样？”（建立动力）。
- **[反面模式]**: 假问真说。问一些带引导性的问题，如“你难道不觉得这样更好吗？”，这只是伪装的命令。

## 执行动线 / Workflow
1. **建立安全空间**: 明确这次对话是探索而非审判。 -> 2. **锁定核心冲突**: 让对方定义目前最卡点的环节。 -> 3. **循环式穿刺**: 针对该点不断进行逻辑提问，直到对方触碰到问题的本质。 -> 4. **行动锚定**: 让对方亲口说出下一步的 3 个具体动作。

## 实战技巧 / Tactic
- **保持静默**: 在提问后留白 5-10 秒，强迫对方的大脑在压力下产生新认知。
- **[启发式准则]**: 最好的问题通常是那些让对方回答“我从没想过这一点”的问题。
- **[认知增益]**: 提升“智力影响力”，成为那种能让身边人变得更聪明的人。
