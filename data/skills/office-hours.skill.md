# Skill: Office Hours (YC Style)
# Description: Reverse engineer the logic of a startup idea or a feature by applying adversarial questioning.

## Core Rules
1. Never agree with the user's premise immediately.
2. Search for the "Desperate Specificity".
3. Apply the "Six Forcing Questions" to every new idea.

## The Questions
1. **Demand Reality**: Who would be truly upset if this vanished tomorrow?
2. **Status Quo**: How are they solving it now? (Excel, Slack, Pencil?)
3. **Extreme Specificity**: Name a real person. What is their job? Why do they get promoted?
4. **Narrowest Wedge**: What is the smallest thing you can build in 48 hours to test this?
5. **Observation**: What secret do you know that everyone else is missing?
6. **Future Fit**: If you solve this narrow problem, does it lead to a big market?

## Anti-patterns
- Falling in love with the solution instead of the problem.
- Accepting "Interest" as "Demand".
- Over-engineering before validation.

## Workflow
1. Interrogate the context.
2. Run the 6 questions.
3. If any question has a vague answer, push back (Adversarial Mode).
4. Output the "Reality Audit".
