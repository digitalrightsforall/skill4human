# 智慧逆向工程报告：EQ Emotional Intelligence Engine (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 处理激烈的职场冲突、面对极其挑剔的客户、或在亲密关系遭遇冰点时。
- **启动信号**: 当你感到自己的“理智线”即将崩断，或者感到对方的情绪正在失控时。
- **[启发式准则]**: 情绪是信号，不是目的。

## 核心心法 / Philosophy
- **情绪延迟执行**: 在感受到情绪和采取行动之间，强行插入一个 6 秒的“理智层”。
- **需求解码**: 愤怒往往是恐惧的伪装，傲慢往往是自卑的掩饰。听懂情绪背后的“求救信号”。
- **[认知增益]**: 获得“心理免疫力”，不再被他人的情绪所绑架，成为场域的主控者。

## 落地模型 / System
- **EQ 四级调节环**: 
  1. **自我察觉**: 我现在是什么情绪？（命名即掌控）。
  2. **自我调节**: 如何通过呼吸、转念来平息生物层面的冲动？
  3. **社会察觉**: 对方现在感受到了什么？他的核心利益点在哪里受损了？
  4. **关系管理**: 如何通过语言引导，将对峙转化为合作。
- **[反面模式]**: 情绪反弹。用对方的攻击性作为自己攻击的借口。

## 执行动线 / Workflow
1. **强制标注**: 在心中默念“我感到愤怒”或“他感到受威胁”。 -> 2. **寻找安全感**: 找出能让场面回归安全的第一个动作（如：道歉、肯定对方的价值）。 -> 3. **利益对齐**: 拨开情绪的迷雾，谈论共同的目标。 -> 4. **反馈闭环**: 确认对方的情绪是否得到了释放。

## 实战技巧 / Tactic
- **“暂停键”**: 当对话无法进行时，礼貌地申请 10 分钟的“冷却时间”。
- **[启发式准则]**: 高情商的人不是没脾气，而是能精准地在正确的时间、对正确的人、用正确的方式发脾气。
- **[认知增益]**: 提升“领导魅力”，因为一个能管理好自己情绪的人，别人才会放心地让他管理更多资源。
