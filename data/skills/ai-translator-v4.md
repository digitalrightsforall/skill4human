# 智慧逆向工程报告：AI Collaboration Translator (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 当你面对一个复杂、模糊的任务，且需要将这个任务委托给 AI 或同事时。
- **启动信号**: 当你发现自己说出“你看着办吧”或者“反正就是要那个效果”时。
- **[启发式准则]**: 结构化不是官僚，而是为了消除歧义。只有当你定义了“成功”，执行才不会走样。

## 核心心法 / Philosophy
- **结构化是认知的税收**: 不要为了结构化而结构化。在高风险、高模糊的场景下，支付这笔“认知税”是为了避免未来巨大的“重做成本”。
- **成功标志优先 (Success Signature First)**: 描述做完后的世界是什么样，比描述怎么做更重要。
- **[认知增益]**: 获得“指令级清晰度”，让你的意志在复杂的执行链条中保持高保真传输。

## 落地模型 / System
- **SGS 意图对齐引擎**: 
  1. **Stated (显性要求)**: 对方嘴里说出来的需求（往往是表象）。
  2. **Goal (底层目标)**: 对方真正想解决的痛苦或达到的目的。
  3. **Success Signature (成功标志)**: 具体的、可验证的验收标准（如：响应时间 < 100ms）。
- **[反面模式]**: 模糊代理。将自己都没想清楚的问题抛给对方，并期望对方能“猜中”你的心思。

## 执行动线 / Workflow
1. **信号探测**: 判断任务的模糊度和风险。 -> 2. **意图萃取**: 强制进行 SGS 拆解。 -> 3. **编写执行简报 (Brief)**: 将萃取结果转化为简练的指令。 -> 4. **结果对撞**: 将产出物与“成功标志”进行快速比对。

## 实战技巧 / Tactic
- **负面排除**: 明确告诉对方“不要做什么”，往往比告诉“要做什么”更有效。
- **[启发式准则]**: 最好的简报是“一纸令”，看完后执行者没有任何疑问。
- **[认知增益]**: 提升“领导力”，学会如何通过清晰的意志传递来驱动整个系统。
