# 智慧逆向工程报告：Analogy Engine (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 学习全新的、极其抽象的概念（如：量子力学、新的编程框架）时，或者需要向外行解释复杂技术时。
- **启动信号**: 当你感到“这个概念太抽象了，摸不到边”时。
- **[启发式准则]**: 所有的理解本质上都是某种形式的类比。

## 核心心法 / Philosophy
- **跨界联觉**: 寻找不同领域之间底层的“同构性”（Isomorphism）。
- **脚手架逻辑**: 类比只是理解的“临时脚手架”，一旦理解完成，就要及时拆除，避免过度类比带来的误导。
- **[认知增益]**: 获得“秒懂”的能力，极大缩短新知识的半衰期。

## 落地模型 / System
- **类比三要素**: 
  1. **Source (源域)**: 你非常熟悉的旧领域（如：流水线）。
  2. **Target (目标域)**: 你不熟悉的新领域（如：并发编程）。
  3. **Mapping (映射)**: 找出源域中的“传送带”对应目标域中的什么？“工位”对应什么？
- **[反面模式]**: 表面类比。只看到形状像，而没有看到底层逻辑像。

## 执行动线 / Workflow
1. **寻找锚点**: 在你已有的知识库中搜索与新概念逻辑相似的旧概念。 -> 2. **建立链接**: 强制写下 3 个映射点。 -> 3. **边界探测**: 找出类比在哪里失效（这个步骤最重要，防止误导）。 -> 4. **概念收口**: 用新领域的原生术语替换掉类比词汇。

## 实战技巧 / Tactic
- **生活化映射**: “这个算法就像在杂乱的抽屉里找袜子……”
- **[启发式准则]**: 一个好的类比应该能产生“哇，原来是这样”的瞬间觉醒。
- **[认知增益]**: 提升“沟通效率”，成为那个能把复杂事情讲简单的高手。
