# 智慧逆向工程报告：Elite Elicitation Tactics (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 进行深度需求调研、处理复杂的利益方关系、或在职场中探测“水面下的真相”时。
- **启动信号**: 当你发现正式的访谈（Interview）无法获得真实回答，对方在用官话应付你时。
- **[启发式准则]**: 最有价值的情报通常不是问出来的，而是对方“不经意间”给出的。

## 核心心法 / Philosophy
- **消除防御**: 让人感到安全是获取信息的前提。不要像审讯官，要像一个好奇的合作伙伴。
- **利用人类天性**: 利用人们“纠正错误”的冲动和“展示专业”的愿望来引导信息流。
- **[认知增益]**: 获得“情报级洞察力”，看透表象背后的真实逻辑和潜规则。

## 落地模型 / System
- **萃取四剑客**: 
  1. **故意犯错 (Presumptive Statement)**: 故意说一个稍微错误的数字（如：听说你们项目预算有 500 万？），引诱对方纠正（不，其实只有 200 万）。
  2. **赞美引导**: 赞美对方在某方面的专业，引导其为了维持专业形象而透露细节。
  3. **倾斜式沉默**: 在对方说完后保持沉默，利用尴尬迫使对方补充更多信息。
  4. **共同敌人**: 通过吐槽一个共同的“槽点”来快速建立战壕友谊。
- **[反面模式]**: 直球式提问。问一些带压力的闭合性问题，这会让对方立即进入防御模式。

## 执行动线 / Workflow
1. **设定目标**: 明确你想获取的那个“核心数据点”。 -> 2. **设计切口**: 寻找一个自然的话题切入点。 -> 3. **进行“无痛萃取”**: 交替使用上述战术进行信息采集。 -> 4. **交叉验证**: 将收集到的零散信息与已知事实进行拼图式还原。

## 实战技巧 / Tactic
- **“听起来……”**: 用标注法命名对方的处境，诱发其深层表达。
- **[启发式准则]**: 如果对方在对话结束后觉得和你聊得很开心，且完全没意识到自己泄露了什么，那你的萃取就成功了。
- **[认知增益]**: 提升“沟通穿透力”，在复杂的社交场中掌握主动权。
