# 智慧逆向工程报告：Context-Aware AI Translator (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 翻译专业论文、文学作品或具有深层语境的商业邮件时。
- **启动信号**: 当直译结果让你感到“虽然单词都对，但读起来像机器人”时。
- **[启发式准则]**: 翻译不是语词的替换，而是“意图的迁徙”。

## 核心心法 / Philosophy
- **神会胜于形似**: 捕捉作者的语气（Tone）和子文本（Subtext）。
- **文化转码**: 将源语言的隐喻转化为目标语言中等效的认知锚点。
- **[认知增益]**: 获得“跨文化沟通”的深度，让你的表达在任何语言中都具有本地灵魂。

## 落地模型 / System
- **三步研磨法 (The Baoyu Method)**: 
  1. **直译 (Literal)**: 确保信息完整，不丢点。
  2. **意译 (Sense)**: 调整语序，修正歧义，使其符合母语习惯。
  3. **神译 (Polish)**: 注入风格。是极简主义？还是华丽修辞？确保韵律感。
- **[反面模式]**: 词典翻译。过度纠结于单个单词的字典含义，而忽略了整句的情绪流动。

## 执行动线 / Workflow
1. **角色设定**: 告诉 AI 它现在是一个“拥有 20 年经验的资深译者”。 -> 2. **语境注入**: 提供原文的背景、受众和目的。 -> 3. **多版本对撞**: 让 AI 给出 3 个不同风格的版本进行对比。 -> 4. **人工终审**: 挑选那个最能触动你的版本并进行微调。

## 实战技巧 / Tactic
- **成语脱敏**: 除非语境极度正式，否则避免使用死板的成语，用鲜活的动词代替。
- **[启发式准则]**: 如果翻译后的句子需要读两遍才能懂，那就是翻译失败。
- **[认知增益]**: 消除“语言障碍”带来的智力折扣，让你的思想在全球市场全额流通。
