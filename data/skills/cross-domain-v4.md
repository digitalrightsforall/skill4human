# 智慧逆向工程报告：Cross-Domain Knowledge Synthesis (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 进入完全陌生的行业、解决跨学科难题、或需要进行突破性创新时。
- **启动信号**: 当你在新领域感到“每个概念都似曾相识，但又说不清楚”时。
- **[启发式准则]**: 创新本质上是旧元素在新环境下的重新排列组合。

## 核心心法 / Philosophy
- **抽象层迁移**: 不要迁移具体的结论，要迁移底层的“逻辑结构”。
- **知识折旧管理**: 意识到哪些知识是“具体的、易碎的”，哪些是“永恒的、稳固的”。
- **[认知增益]**: 获得“降维打击”的能力，利用旧领域的深度去破解新领域的广度。

## 落地模型 / System
- **迁移三部曲**: 
  1. **去语境化 (De-contextualization)**: 剥离掉原领域的名词，只保留逻辑内核（如：供需关系、熵增、反馈环）。
  2. **同构映射 (Mapping)**: 在新领域寻找具有相同结构的锚点。
  3. **再语境化 (Re-contextualization)**: 用新领域的“方言”重新表达该逻辑。
- **[反面模式]**: 生搬硬套。不考虑新领域的特有变量，强行复用旧方案。

## 执行动线 / Workflow
1. **识别核心逻辑**: 问“这个东西运行的最底层规律是什么？” -> 2. **搜索相似结构**: “在我的知识库里，还有什么长成这样？” -> 3. **进行压力测试**: 这种迁移在极端情况下会失效吗？ -> 4. **产出新洞察**: 形成在该领域独一无二的竞争优势。

## 实战技巧 / Tactic
- **多读书，读杂书**: 建立庞大的源域（Source domain）库。
- **[启发式准则]**: 如果你觉得一个领域很难懂，那说明你还没找到它与你已知领域的那个“连接桥”。
- **[认知增益]**: 提升“思维的广度”，成为那个在会议室里能提供“意外视角”的人。
