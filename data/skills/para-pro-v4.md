# 智慧逆向工程报告：PARA Actionable Organization (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 你的电脑桌面、云端硬盘、笔记软件陷入一片混乱，找东西需要超过 1 分钟时。
- **启动信号**: 当你感到“信息过载”且不知道手头的事情该归档到哪里时。
- **[启发式准则]**: 知识的存储方式应该反映它的“生命周期”。

## 核心心法 / Philosophy
- **行动导向**: 分类标准不是“它是什么”，而是“我什么时候要用它”。
- **流动的系统**: 文件夹不是死牢，信息应该在四个维度之间根据状态自由流动。
- **[认知增益]**: 获得“极简的数字生活”，将 90% 的整理带宽释放给真实的创造。

## 落地模型 / System
- **PARA 四层架构**: 
  1. **Projects (项目)**: 有明确截止日期的任务（如：写完这篇报告）。
  2. **Areas (领域)**: 长期需要维护的标准（如：健康、财务）。
  3. **Resources (资源)**: 感兴趣但暂无行动的素材。
  4. **Archives (归档)**: 已完成或已冷却的信息。
- **[反面模式]**: 按照学科分类。建立“心理学”、“历史”这种文件夹，会导致信息在需要时极难被检索。

## 执行动线 / Workflow
1. **瞬间决策**: 看到一个文件，5 秒内决定它属于 P、A、R 还是 A。 -> 2. **动态迁移**: 项目结束后，立即将其所有素材移入归档或资源区。 -> 3. **周清算**: 检查项目区，确保所有东西都在推进中。 -> 4. **零阻力检索**: 只在项目区工作，减少大脑的上下文切换。

## 实战技巧 / Tactic
- **文件夹扁平化**: 每个层级下不要超过 10 个子项。
- **[启发式准则]**: 最好的组织系统是那个你不需要动脑筋就能把东西放对位置的系统。
- **[认知增益]**: 提升“执行力”，让你的所有素材都时刻处于“随时待命”状态。
