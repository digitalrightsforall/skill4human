# 智慧逆向工程报告：Academic Paper Adversarial Reviewer (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 论文初稿完成、准备提交会议或期刊前的终审阶段。
- **启动信号**: 当你自我感觉良好，觉得“逻辑无懈可击”时。
- **[启发式准则]**: 审稿人的工作不是寻找你的优点，而是寻找拒绝你的理由。

## 核心心法 / Philosophy
- **学术诚实与边界**: 承认你的局限性（Limitations）比掩盖它们更能获得信任。
- **具体性是唯一硬通货**: 模糊的结论是垃圾，只有带置信区间的实验数据才有说服力。
- **[认知增益]**: 获得“降维打击”的审视视角，在学术竞争中保持极高的防御力。

## 落地模型 / System
- **五维度爆破自检 (5-Point Audit)**: 
  1. **Novelty (创新性)**: 这个点子如果是 5 年前做的，还有价值吗？
  2. **Soundness (严谨性)**: 实验是否排除了所有明显的混淆变量（Confounding Variables）？
  3. **Reproducibility (可复现性)**: 如果我把你的代码丢给一个研一新生，他能跑出同样的结果吗？
  4. **Clarity (清晰度)**: 图表是否能在不看正文的情况下传达核心信息？
  5. **Significance (影响力)**: 除了你自己，谁会真正关心这个结论？
- **[反面模式]**: 强行升华。在讨论部分（Discussion）把一个小小的实验结果吹嘘成改变世界的发现。

## 执行动线 / Workflow
1. **身份切换**: 扮演一个刚才被实验室老板骂了一顿、心情极度糟糕的审稿人。 -> 2. **逻辑穿刺**: 寻找每一段话中的“Assumption”（假设）。 -> 3. **反向求证**: 问自己“如果这个结论是错的，最可能的原因是什么？” -> 4. **补丁强化**: 针对漏洞补充 Baseline 实验或解释。

## 实战技巧 / Tactic
- **Abstract 压力测试**: 如果只读摘要，我能写出你的实验方案吗？如果不能，说明摘要太虚。
- **[启发式准则]**: 最好的防御是在审稿人提问之前，你已经在 Limitation 章节里自己提出来了。
- **[认知增益]**: 提升思维的严密度，不仅在学术界，在任何需要逻辑说服力的场景都能胜出。
