# 智慧逆向工程报告：High-Precision Writing Coach (v4.7)

## 适用时机 / Timing & Context
- **典型情景**: 撰写正式报告、商业邮件、书籍手稿或任何需要极高清晰度的文字场景。
- **启动信号**: 当你发现自己写出的句子超过 30 个字，且充斥着抽象名词时。
- **[启发式准则]**: 写作的艺术在于删减。

## 核心心法 / Philosophy
- **消除杂质 (Clutter)**: 删掉每一个没有实际意义的形容词和副词（如：非常、特别、显著）。
- **动词为王**: 使用鲜活的、有力量的动词。把“进行了一次调查”改为“调查了”。
- **[认知增益]**: 获得“文字穿透力”，让读者的注意力直接触碰到你的思想核心。

## 落地模型 / System
- **清晰度四要素**: 
  1. **Unity (统一性)**: 全文是否只有一个核心观点？
  2. **Economy (经济性)**: 是否用了最少的字表达了最完整的意思？
  3. **Clarity (透明度)**: 读者能否一眼看出主语和谓语？
  4. **Pace (节奏感)**: 长句与短句的交替使用，产生呼吸感。
- **[反面模式]**: 官僚体。使用大量的被动语态和模糊词汇来掩盖思想的空洞。

## 执行动线 / Workflow
1. **自由书写**: 先不管质量，把所有念头倾倒出来。 -> 2. **外科手术式删减**: 删掉 50% 的废话。 -> 3. **逻辑重组**: 确保每一段只讲一个核心点。 -> 4. **朗读测试**: 大声读出来，凡是让你感到“气短”的地方，就是需要拆分或删减的地方。

## 实战技巧 / Tactic
- **干掉“的、了、呢”**: 检查你的助词，大部分都可以删掉。
- **[启发式准则]**: 如果你不能用一句话概括出一段话的意义，那说明这段话还没写清楚。
- **[认知增益]**: 提升“思考质量”，因为模糊的写作往往反映了模糊的思考。
