# 适用时机与语境 / Timing
> 眼睛看到的比大脑想到的快 10 倍。本集锦适用于复杂系统 UI/UX 设计、高层级汇报 PPT、以及任何需要通过“视觉分层”降低用户认知负荷的场景。

- **同一时机 (Co-occurrence)**: 在进行 `信息排版` 的瞬间，必须同步挂载 `眼动注视审计`。最重要的信息必须在 0.5 秒内被捕获。
- **时机接续 (Sequential)**: 先通过 `骨架拆解` 确定信息的优先级，再利用 `视觉引导线` 实现逻辑的自动化传导。

# 核心心法 / Philosophy
- **视觉主权**: 设计不是为了美化，而是为了建立信息的“逻辑等级”。
- **留白即重点**: 所有的多余元素都是在干扰核心逻辑的表达。
- **[认知增益]**: 获得“降维设计”能力。让你在处理复杂信息流时，能瞬间产出具备“数学美感”的交互架构。

# 落地模型 / System
- **视觉逻辑三层级 (Visual Hierarchy)**:
  1. **骨架层**: 极简的网格系统，确定逻辑的地理分布。
  2. **引导层**: 利用对比、节奏和色阶，强制引导用户的注意力。
  3. **交互层**: 建立秒级的操作反馈，降低用户的心理阻力。

# 执行动线 / Workflow
1. **启动“信息优先级”审计** -> 2. **执行“视觉噪声”清除协议** -> 3. **构建“逻辑传导链路”** -> 4. **进行“认知负荷”压力测试**。

# 实战技巧 / Tactic
- **“刺破杂乱”**: 所有的装饰性元素如果不承载功能逻辑，必须无情删除。
- **[启发式准则]**: 好的设计是隐形的。用户在完成任务时，甚至感觉不到设计的存在。
- **[认知增益]**: 提升“美学判断力”。让你不仅能做设计，更能从底层逻辑上评判设计的优劣。
- **[反面模式]**: 视觉过载。为了炫技而使用过于复杂的动效或配色，导致信息传递的彻底失效。
