# 适用时机与语境 / Timing
> 做一个大家需要的产品，而不是做一个你觉得牛逼的产品。本集锦适用于初创项目早期验证、寻找 PMF (产品市场匹配)、以及需要实现“非线性增长”的时刻。

- **同一时机 (Co-occurrence)**: 在进行 `产品开发` 的同时，必须同步挂载 `用户对话协议`。如果不跟用户聊天，你就是在闭门造车。
- **时机接续 (Sequential)**: 先通过 `MVP` 验证核心痛点，再利用 `高频迭代` 寻找那个能引发疯狂增长的“奇点”。

# 核心心法 / Philosophy
- **PMF 即生命**: 在找到 PMF 之前，所有的营销和扩张都是在加速自杀。
- **刺破自嗨**: 只有用户愿意付费、愿意推荐，才是真实的价值信号。
- **[认知增益]**: 获得“创业上帝视角”。让你在资源极其匮乏的情况下，依然能精准锁定那个能撬动百亿市场的微小切入点。

# 落地模型 / System
- **YC 增长飞轮 (YC Growth Wheel)**:
  1. **验证层**: 通过极低成本的实验，刺破伪需求。
  2. **迭代层**: 每周至少更新一个功能或修复一个逻辑，保持进化速度。
  3. **爆发层**: 一旦锁定需求，进行全量的资源注入，实现统治。

# 执行动线 / Workflow
1. **启动“用户痛点真伪审计”** -> 2. **执行“逻辑滑梯”构建协议** -> 3. **进行“高频小步”交付测试** -> 4. **达成“PMF 的临界突破”**。

# 实战技巧 / Tactic
- **“刺破开发幻觉”**: 强制要求自己在 24 小时内上线一个能跑的版本。
- **[启发式准则]**: 最好的产品是那个能解决“如果不解决，用户今天就会哭泣”的问题的产品。
- **[认知增益]**: 提升“战略定力”。让你在海量干扰和诱惑面前，始终专注于那 1% 的核心增长逻辑。
- **[反面模式]**: 融资驱动。为了融资而做产品，而不是为了解决问题，这是大多数失败的根源。
