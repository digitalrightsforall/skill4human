# 适用时机与语境 / Timing
> 简单是复杂到了极致的产物。本集锦适用于超大规模项目架构设计、产品核心价值提炼、以及任何需要通过“降维”来实现“升维打击”的时刻。

- **同一时机 (Co-occurrence)**: 在进行 `信息罗列` 的瞬间，必须同步挂载 `奥卡姆剃刀`。如无必要，勿增实体。
- **时机接续 (Sequential)**: 先通过 `全量拆解` 理解系统的全部复杂，再利用 `逻辑压缩` 寻找那个能控制全局的极简公式。

# 核心心法 / Philosophy
- **信息熵减**: 价值不在于你提供了多少，而在于你帮对方排除了多少干扰。
- **刺破装饰**: 所有的修饰都是对核心逻辑的背叛。
- **[认知增益]**: 获得“降维掌控力”。让你产出的每一个方案都具备“不可被删除一笔”的完美张力。

# 落地模型 / System
- **简约大师架构 (Simplicity Mastery)**:
  1. **蒸馏层**: 提取事物的“物理本质”。
  2. **脱水层**: 剔除所有冗余的背景、噪音和过渡。
  3. **固化层**: 用最直观、最具冲击力的形式还原真相。

# 执行动线 / Workflow
1. **启动“复杂度”深度审计** -> 2. **执行“逻辑原液”提炼协议** -> 3. **进行“心智承载”压力测试** -> 4. **下达“极致简洁”执行指令**。

# 实战技巧 / Tactic
- **“刺破废话”**: 强行要求自己将 1 小时的会议内容缩减为 1 分钟的简报，看核心逻辑是否依然稳固。
- **[启发式准则]**: 最好的设计不是没有东西可以增加，而是没有东西可以减少。
- **[认知增益]**: 提升“战略定力”。让你在海量信息流中保持清醒，不被表面现象所诱导。
- **[反面模式]**: 浅薄的简单。因为不懂复杂而导致的简单，那只是简陋。
