# 适用时机与语境 / Timing
> 进步不是自动发生的，而是被审计出来的。本集锦适用于长周期个人成长计划、核心项目的中期评估、以及需要从“平庸的循环”中强行切出的时刻。

- **同一时机 (Co-occurrence)**: 在进行 `执行复盘` 的同时，必须同步挂载 `假设审计`。问：我当时的那个决策，是基于哪些“不可靠的隐性假设”做出的？
- **时机接续 (Sequential)**: 先通过 `数据尸检` 找到逻辑断点，再通过 `递归修正` 实现系统协议的迭代。

# 核心心法 / Philosophy
- **递归进化**: 不断地审视“审视本身”，找出认知偏差的偏差。
- **冷酷实证**: 拒绝任何自我安慰，只对真实的数据和逻辑结果负责。
- **[认知增益]**: 获得“自进化掌控力”。让你具备一套能够自动识别自身盲区并强制执行升级的“递归大脑”。

# 落地模型 / System
- **递归审计系统 (Recursive Audit)**:
  1. **执行层**: 记录真实的动作与偏差。
  2. **模型层**: 审计底层的决策模型是否已经失效。
  3. **写入层**: 强制更新系统协议，确保同一类型的逻辑错误绝不再犯。

# 执行动线 / Workflow
1. **启动“认知偏差”深度探测** -> 2. **执行“逻辑奇点”锁定协议** -> 3. **完成“系统自升级”指令** -> 4. **下达“带伤进化”命令**。

# 实战技巧 / Tactic
- **“刺破面子幻觉”**: 只有彻底承认自己的逻辑愚蠢，才有可能获得真实的逻辑升级。
- **[启发式准则]**: 最好的复盘不是总结经验，而是找出那个让你以后绝不会再掉进去的“深坑”。
- **[认知增益]**: 提升“战略定力”。让你在任何长期博弈中都能通过稳健的逻辑进化锁定胜局。
- **[反面模式]**: 浅尝辄止。只修正动作而不触及底层逻辑，导致错误在新的场景下反复出现。
