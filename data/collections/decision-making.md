# 适用时机与语境 / Timing
> 决策的质量决定了企业的天花板。本集锦适用于重大战略制定、高管评审、以及需要刺破“虚假共识”的关键时刻。

- **同一时机 (Co-occurrence)**: 在进行 `现状诊断` 的同时，必须强制引入 `对抗性审讯`。不要寻找“支持论据”，要寻找“自毁细节”。
- **时机接续 (Sequential)**: 先通过 `Office Hours` 逻辑挤干假设中的水分，再进入 `OKR` 映射环节，将共识转化为物理拉力。

# 核心心法 / Philosophy
- **刺破幻觉**: 所有的战略失败都始于对现状的“温柔美化”。
- **概率主权**: 决策不是赌博，而是通过严密的审计程序，将风险降至可承受范围内的科学。
- **[认知增益]**: 获得“上帝视角”的替代品——一套确定的、可重复的、对抗平庸的决策流水线。

# 落地模型 / System
- **决策三环逻辑 (The Decision Loop)**:
  1. **审计环 (Audit)**: 挑战核心前提的真实性。问：如果这是错的，代价是什么？
  2. **锚定环 (Anchoring)**: 将抽象的共识具象化为不可辩驳的数字和动作。
  3. **校准环 (Calibration)**: 通过复盘剥离运气成分，提炼系统性的逻辑偏差。

# 执行动线 / Workflow
1. **启动“刺破幻觉”问询协议** -> 2. **进行“北极星翻译”** (将战略目标转化为 3 个关键拉力指标) -> 3. **执行“尸检报告 (Retro)”模式** (在事情尚未开始前先预测其失败逻辑) -> 4. **下达“确定性指令”**。

# 实战技巧 / Tactic
- **“如果没有这个，谁会哭泣？”**: 用这个极简问题来测试项目的核心价值。
- **[启发式准则]**: 决策质量不取决于开会的时长，而取决于你敢于推翻多少个“大家都觉得还行”的计划。
- **[认知增益]**: 提升“战略定力”，在纷繁复杂的信息流中保持清醒。
- **[反面模式]**: 决策孤岛。只做诊断不设指标，或只设指标不复盘。
