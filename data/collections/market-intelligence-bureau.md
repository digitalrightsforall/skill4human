# 适用时机与语境 / Timing
> 商业决策不能靠拍脑袋。本集锦适用于竞品调研、进入新赛道评估、或需要看穿行业对手“虚张声势”的时刻。

- **同一时机 (Co-occurrence)**: 在采集 `公开财务数据` 的同时，必须同步进行 `用户情感地图` 审计。数字是冷冰冰的，而情绪是真实的方向。
- **时机接续 (Sequential)**: 先通过 `全量竞品拆解` 找到对手的防御漏洞，再利用 `蓝海搜索` 寻找那个被巨头忽视的边缘奇点。

# 核心心法 / Philosophy
- **穿透表象**: 所有的商业动作背后都有其不可言说的“灵魂”。情报工作的本质是重构对手的决策大脑。
- **信号大于噪音**: 在海量信息中寻找那个“不可磨灭的事实”，而不是被公关稿和虚假数据迷惑。
- **[认知增益]**: 获得“上帝视角”。让你在竞争中总是能领先对手一步，提前在对方的必经之路上埋伏好。

# 落地模型 / System
- **情报提炼三层架构 (Intelligence Synthesis)**:
  1. **资产审计层**: 调研对手的真实资源、人才结构和技术红利。
  2. **逻辑拆解层**: 还原对手的增长飞轮及其最脆弱的支撑点。
  3. **机会奇点层**: 基于对手的盲区，定义属于你的差异化进场协议。

# 执行动线 / Workflow
1. **启动“全景竞品深度剥离”协议** (拆解到原子级的定价与功能逻辑) -> 2. **建立“真实用户槽点地图”** -> 3. **执行“市场空白点”压力测试** -> 4. **下达“针对性打击”决策建议**。

# 实战技巧 / Tactic
- **“评论区挖掘”**: 竞品的差评区就是你产品蓝图的起点。
- **[启发式准则]**: 最好的商业情报不是秘密，而是对公开事实的“反直觉解读”。
- **[认知增益]**: 提升“商业敏锐度”。让你不仅能看懂对手在干什么，更能看懂他为什么不得不这么干。
- **[反面模式]**: 盲目跟风。看到对手做什么就跟着做什么，这本质上是把决策权交给了对方。
