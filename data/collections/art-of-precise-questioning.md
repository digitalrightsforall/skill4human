# 适用时机与语境 / Timing
> 问题的质量决定了答案的边界。本集锦适用于你需要引导深度对话、挖掘业务根因、或在信息极度不对称的情况下进行防御性审计的时刻。

- **同一时机 (Co-occurrence)**: 当你进行 `开放式提问` 进行发散搜索时，必须同步挂载 `逻辑假设审计`。不要漫无目的地问，要带着“可能的真相”去验证。
- **时机接续 (Sequential)**: 先通过 `漏斗式问询` 锁定模糊地带，再切换到 `极端案例问询` 迫使对方暴露底层逻辑。

# 核心心法 / Philosophy
- **提问即干预**: 每一个问题都在重塑对方的思考路径。
- **刺破舒适区**: 最好的提问是那个让对方感到“有点不舒服、但必须思考”的决定性瞬间。
- **[认知增益]**: 获得“思维探针”能力。让你在任何复杂局势中都能通过 3 个关键问题迅速锁定全局最脆弱的环节。

# 落地模型 / System
- **多维问询矩阵 (The Questioning Matrix)**:
  1. **诊断层**: 识别现状中的“已知”与“未知的未知”。
  2. **反事实层**: 挑战当前的惯性路径。问：如果没有这个变量，系统会崩塌吗？
  3. **奇点层**: 锁定那个一旦解决，所有衍生问题都会消失的核心节点。

# 执行动线 / Workflow
1. **启动“逻辑真空”探测** (询问那些大家默认不需要问的基本假设) -> 2. **执行“深度下钻”协议** (追问逻辑链条的第 3 层因果) -> 3. **进行“场景压力测试”问询** -> 4. **完成“认知闭环确认”**。

# 实战技巧 / Tactic
- **“停顿的力量”**: 在提问后保持 5 秒的沉默，迫使对方吐露出被粉饰过的真实细节。
- **[启发式准则]**: 最好的答案往往藏在那个“大家都觉得没必要问”的问题里。
- **[认知增益]**: 提升“认知穿透力”。让你在海量信息流中保持独立判断，不被情绪化的叙事干扰。
- **[反面模式]**: 诱导性提问。为了得到自己想要的答案而预设立场，这会导致严重的决策误导。
