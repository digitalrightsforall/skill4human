核心策略： 采用静态站点生成 (SSG) 配合 GitHub Actions。在部署时运行扫描脚本，生成静态 JSON 数据库，从而实现 0 成本、极速访问。

AI 能力要求

  • 深度语义识别：理解 if-then 后的专家意图。
  • 高维打分：跨 Skill 维度的智慧密度对齐。
  • 模型：指定使用 Gemini 2.0 / 3.0 或 Claude 3.5 系列。

部署限制

  • 无需后端服务器：所有分析结果持久化为 JSON。
  • 隐私安全：本地扫描，仅结果上传 GitHub。
