# Skill4Human 用户手册 (User Manual)

## 1. 欢迎来到智慧逆向中心
Skill4Human 旨在帮助您将复杂的 AI 指令转化为人类的实战能力。这里不是工具箱，而是您的思维实验室。

## 2. 核心概念

### 🏛️ 智慧塔 (The Wisdom Tower)
每一个技能都被解构为四个维度，请按顺序阅读：
- **哲学 (Philosophy)**: 解决该问题的底层心法与原则。
- **系统 (System)**: 支撑该能力的逻辑框架与思维模型。
- **流程 (Workflow)**: 可复制的标准化执行步骤。
- **战术 (Tactic)**: 具体的实战技巧与避坑指南。

### 🚀 实战剧本 (Playbook)
在“集锦”板块中，我们为您准备了合成后的剧本。它直接回答“如何解决特定场景问题”，您可以点击 **[复制系统提示词]** 直接在 AI 聊天中使用。

## 3. 功能操作指南

### 🔍 发现智慧
- **分类筛选**: 通过顶部的分类标签快速定位您感兴趣的领域。
- **全局搜索**: 直接输入关键词（如“写作”、“工程”）检索相关单元。

### 📄 内容编辑 (面向进阶用户)
如果您想修改“关于项目”页面的文字，无需动任何代码：
1.  找到目录 `content/about.md`。
2.  直接修改其中的文本内容。
3.  保存文件，网页端将自动同步更新。

## 4. 参与贡献
本项目遵循「普通人的数字权利」共创原则。
- **提交新技能**: 将解析后的 JSON 放入 `data/skills/`。
- **创建新集锦**: 在 `data/collections/` 中定义您的智慧组合方案。
