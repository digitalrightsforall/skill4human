# Skill 单页重构：破解“高认知、低获得感”的深度危机 (V3)

## 1. 核心危机：为什么看了等于没看？

您指出的问题极其深刻，它直击了目前生成式 AI 知识总结的通病——**知识被极度压缩后，失去了“附着力”**。

当我们用 LLM 去解析（`mass_process.js`）几千字的 `SKILL.md` 原文时，LLM 天然倾向于提取最“高维”、最抽象的原则（如“演进胜于规划”、“减法默认”）。但对于人类学习者而言：
- **只有原则，没有案例（Examples）**，大脑无法建立认知锚点，难以真正理解。
- **只有口号，没有上下文（Context）**，无法转化为实际的行动肌肉，导致“看了等于没看”、“点到即止”的空虚感。

目前的架构过度追求统一的“结构化”和“精简”，以牺牲细节和实感为代价，导致了这种深度的危机。

---

## 2. 破局思路：从“提取摘要”到“锚定实战”

要解决这个问题，我们需要在**数据层（分析管道）**和**UI展示层**同时做出改变。核心原则是：**每一个高维抽象的原则，都必须绑定一个低维具象的抓手。**

### 方案 A：数据管道的深度改造 (Pipeline Upgrade)

我们需要在后续升级 `skill4human-analyze` (`mass_process.js`) 的 LLM Prompt。强制要求模型在提取智慧时，不能只给抽象总结，必须携带**原汁原味的佐证**。

**理想的数据结构扩展（未来目标）：**
```json
{
  "wisdom": {
    "layers": [
      {
        "type": "Tactic",
        "title": "减法默认",
        "content": "每个元素必须赚回占用的像素。去掉不影响体验就删掉。",
        // 👇 强制要求从源码提取具体的指令片段或真实案例
        "concrete_example": "原码摘录：'Prioritize CSS-only solutions for HTML. Use Motion library for React...'",
        "context_anchor": "应用场景：当你在设计微交互时..."
      }
    ]
  }
}
```
**价值**：治本。通过强迫提供 `concrete_example`，打破大而空的总结。

### 方案 B：UI 呈现的“渐进式深潜” (Progressive Disclosure)

在不修改底层数据的前提下，前端 UI 设计需要从“干瘪的卡片罗列”变为**“先见骨架，后探血肉”**的结构。

1. **结构与细节的交织**：在展示抽象的 `System` 或 `Tactic` 时，提供视觉交互（如展开面板），引导用户深入查看细节。
2. **源码的高亮引路**：既然 `raw_source` 包含了最丰富的上下文，UI 不应仅仅提供一个干巴巴的“查看源码”按钮。可以在页面尾部或侧边提供引导：“带着这些框架，去探索原始指令的具体实现方式”，鼓励用户在获得框架认知后，主动去吸收源码中的实感。

## 3. 全新信息架构落地蓝图 (基于现有数据)

结合上述思考，我们现在就可以利用**已有数据**，重构出一个能显著提升“获得感”的新版 `SkillDetail.tsx`。

页面心智模型将重组为四大模块：

### 模块一：The Hook（认知价值锚定）
- **解决**：“这东西能改变我什么？”
- **呈现**：通过醒目大字号展示 `human_gain`，直接刺中痛点。

### 模块二：The Core Logic（底层逻辑与机制）
- **解决**：“它的世界观和运转机制是什么？”
- **呈现**：整合现存的 `Philosophy` & `System`。采用沉稳的视觉区块展示核心原则。

### 模块三：The Execution（行动指南与战术）
- **解决**：“我具体该怎么做？”
- **呈现**：
  - **工作流 (Workflow)**：摒弃普通段落，前端通过轻量级正则提取（按 `1.`, `2.` 拆分），将其渲染为**垂直步骤条 (Vertical Stepper)**，强化实操流程感。
  - **战术 (Tactics)**：展示为具体的行动检查清单 (Checklist) 或行动卡片。

### 模块四：The Guardrails（专家护栏：避坑与经验）
- **解决**：“实战中我该怎么判断？有什么雷区？”
- **关键动作**：将目前被遗漏的 `Heuristics`（启发金句）与 `Anti-patterns`（反模式）推到台前！
- **价值**：这两个字段往往比四层塔更具象（例如“周五下午宣布重大架构调整是毒药”），具有极强的实战冲击力。通过高对比度的警示色调（如红色警告/黄色锦囊）展示，能瞬间拉升用户的“获得感”。

## 4. 行动路线与建议

考虑到彻底解决“空洞感”需要触及底层数据生成，我建议采取**两步走战略**：

### 优先执行：当前 UI 的极致重构 (Phase 1)
在此阶段，我们**不修改**现有的 138 个 JSON 数据库，完全通过重构 `SkillDetail.tsx` 榨干现有数据的价值：
1. 重塑四大模块（Hook -> Logic -> Execution -> Guardrails）。
2. 在前端实现正则拆分，将纯文本的 Workflow 升级为可视化步骤条。
3. 暴露并高亮展示 `Heuristics` 和 `Anti-patterns`。

### 后续规划：底层分析管道升级 (Phase 2)
在未来，我们将开启一个专项任务，重写 `skill4human-analyze` 的 Prompt，引入 `concrete_example` 等字段，对库内数据进行“二次提纯”，从而从根源上注入案例和实感。
